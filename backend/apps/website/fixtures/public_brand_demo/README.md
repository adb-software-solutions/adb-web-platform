# Software Solutions and Technology local concepts

Original HTML/CSS application and operational-workspace concepts with fictional
sample data. The sidebar, workflow rows and preview banner make the images useful
for testing software/infrastructure case-study layouts; they are not client work.

`concept.html?brand=software&index=0` through `index=2` renders the Software
concepts. Use `brand=technology` for the infrastructure concepts. The bundled PNGs
were captured at 1400 × 900 with Chromium and loaded into actual CMS image fields
by `seed_public_brand_demo`. Project and article images share the relevant concept.

Do not present these records or images as genuine engagements or endorsements.
The seed requires Django debug mode and a local database host. It is repeatable,
preserves edits, and offers Brand-specific cleanup. See the website app README.
